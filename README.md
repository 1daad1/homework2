## 1. 理论推导（ResNet 残差块的梯度）

**题目**：请写出 ResNet 中权重层 Wₗ 的梯度 ∂L/∂Wₗ 的表达式。它与深层梯度 ∂L/∂xₗ₊₁ 是如何关联的？（提示：利用 xₗ₊₁ = xₗ + F(xₗ, Wₗ) 进行链式求导。）

### 1.1 残差块的前向传播

ResNet 的基本残差块（ResNet v1）定义为：

```
xₗ₊₁ = xₗ + F(xₗ, Wₗ)
```

其中：
- xₗ 是第 l 个残差块的输入；
- F(xₗ, Wₗ) 是"残差函数"，即块内两个（或三个）卷积权重层的非线性变换：F = W₂ · σ(W₁ · xₗ)（省略偏置与 BN）；
- **恒等快捷连接（identity shortcut）** 把 xₗ 直接加到块的输出上。

### 1.2 权重梯度 ∂L/∂Wₗ 的推导

设损失函数为 L。对 Wₗ 使用链式法则：

```
∂L/∂Wₗ = (∂L/∂xₗ₊₁) · (∂xₗ₊₁/∂Wₗ)
```

由 xₗ₊₁ = xₗ + F(xₗ, Wₗ)，注意快捷连接中**不含 Wₗ**，所以：

```
∂xₗ₊₁/∂Wₗ = ∂F(xₗ, Wₗ)/∂Wₗ
```

代回得：

```
∂L/∂Wₗ = (∂L/∂xₗ₊₁) · (∂F(xₗ, Wₗ)/∂Wₗ)
```

**若块内为两层卷积** F(xₗ, Wₗ) = W₂ σ(W₁ xₗ)（记 Wₗ = {W₁, W₂}），对第一层权重 W₁ 具体展开：

```
∂L/∂W₁ = (∂L/∂xₗ₊₁)ᵀ · W₂ · diag(σ'(W₁ xₗ)) · xₗ      （逐样本的外积形式）
```

对第二层权重 W₂：

```
∂L/∂W₂ = (∂L/∂xₗ₊₁)ᵀ · σ(W₁ xₗ)
```

（实现中按批量样本求和/平均即可。）

### 1.3 与深层梯度 ∂L/∂xₗ₊₁ 的关联

关键在于**反向传播时 ∂L/∂xₗ₊₁ 如何传回 xₗ**。对 xₗ 求导：

```
∂L/∂xₗ = (∂L/∂xₗ₊₁) · (∂xₗ₊₁/∂xₗ) = (∂L/∂xₗ₊₁) · ( I + ∂F(xₗ, Wₗ)/∂xₗ )
```

其中 I 是**单位矩阵**，来自恒等快捷连接。由此得到两个重要结论：

**（1）权重梯度 = 深层梯度 × 残差支路的局部雅可比。**

由 1.2 可见，Wₗ 的梯度由两部分相乘得到：来自深层的误差信号 ∂L/∂xₗ₊₁，和残差支路对 Wₗ 的局部导数 ∂F/∂Wₗ。也就是说，**只要深层梯度 ∂L/∂xₗ₊₁ 能顺利传回（不为 0 也不爆炸），浅层权重就能获得有效的学习信号**。ResNet 的设计恰恰保证了前者（见下）。

**（2）恒等路径让误差信号"无损直达"，这就是 ∂L/∂xₗ₊₁ 与浅层关联的桥梁。**

把上式从第 l 层一路展开到第 L 层（损失端）：

```
∂L/∂xₗ = ∂L/∂x_L · ∏_{k=l}^{L-1} ( I + ∂F(xₖ, Wₖ)/∂xₖ )
```

展开连乘（只写前几项示意）：

```
∂L/∂xₗ = ∂L/∂x_L · ( I + ∂Fₗ/∂xₗ + ∂Fₗ₊₁/∂xₗ₊₁ + ∂Fₗ/∂xₗ·∂Fₗ₊₁/∂xₗ₊₁ + … )
```

- **第一项 I**：梯度可以沿着恒等连接**原封不动**地传到任意浅层——即使所有 ∂F/∂x 都很小（权重很小或激活饱和），梯度也至少有一项 ≈ ∂L/∂x_L，**不会指数消失**；
- 其余各项是穿过一个或多个残差支路的"修正项"，即使某一项爆炸，整体也能被单位项"锚定"，不易失控。

**结论**：`∂L/∂Wₗ = (∂L/∂xₗ₊₁)(∂F/∂Wₗ)`，其有效性完全由深层梯度 ∂L/∂xₗ₊₁ 的可达性决定；而恒等快捷连接使 ∂L/∂xₗ₊₁ 能通过单位矩阵项无损回传，从而**从根本上缓解了梯度消失，让数百层的网络可以训练**。这正是 ResNet 论文（He et al., 2016）中"残差映射更容易优化：若恒等映射已是最优，只需把 F 压向 0"的理论解释。

## 2. 思考与对比

### 2.a Highway Networks 与 ResNet 在快捷连接上的异同

**背景**：Highway Networks（Srivastava et al., 2015，NIPS）与 ResNet（He et al., 2016，CVPR）几乎同时提出，都使用"带快捷连接"的跨层通路来缓解梯度消失，但机制不同。

**Highway Network 的块定义**（借鉴 LSTM 门控思想）：

```
y = H(x, W_H) · T(x, W_T) + x · C(x, W_C)
```

其中：
- H(x, W_H)：普通的非线性变换支路（"被门控的主路"）；
- **T(x, W_T)：变换门（Transform gate）**，控制有多少信息走变换支路 H；
- **C(x, W_C)：携带门（Carry gate）**，控制有多少信息直接透传。通常令 C = 1 − T，于是：

```
y = H(x, W_H) · T(x, W_T) + x · (1 − T(x, W_T))
```

当 T = 1 时退化为普通层（y = H）；当 T = 0 时退化为纯恒等映射（y = x），由网络**自己学**什么时候开门、什么时候关门。

**对比表**：

| 维度 | Highway Network | ResNet |
|---|---|---|
| 连接形式 | y = H·T + x·(1−T) | y = x + F(x, W) |
| 快捷连接是否有参数 | **有**：门控 T、C 是需学习的函数（带权重） | **无**：恒等连接 I 固定、零参数 |
| 信息通路 | 由数据驱动的**可学习门控**动态决定走主路还是短路 | 始终**无条件**地把输入加到输出上 |
| 梯度回传 | 需要穿过门控的雅可比 ∂T/∂x 等，门控本身可能退化或饱和 | 恒等项 I 保证梯度分量恒为 1，永远存在"无损直达"通路 |
| 特例关系 | 当 T ≡ 1 时退化为普通网络；T ≡ 0 时为恒等 | 可看作"把门固定为半开（T=0.5 且 C=0.5 的结构特例）"的 Highway，但 ResNet 并非 Highway 的严格特例（两者结构不同） |
| 初衷侧重 | 让**非常深的 plain 网络可训练**（最初在 100+ 层全连接上验证） | 让**深层卷积网络**易于优化，残差学习公式化（F = H − x） |
| 实现开销 | 每个块多两套门控参数与逐元素运算，**参数和计算量更大** | 仅需一个逐元素加法，**几乎零开销** |

**相同点**：两者都允许信息（和梯度）绕过非线性变换层直接跨层流动，从而缓解梯度消失、支持上百层的网络训练。

**本质差异**：Highway 用**学习的门控**来"选择"信息通路（灵活性高但引入了额外的可训练部件和优化复杂度，门控可能学偏）；ResNet 用**无参数的恒等加法**把通路"永远打开"（更简单、开销更小，且恒等项保证了梯度的解析可达性）。实践上 ResNet 的简洁设计使其成为视觉任务的主流骨架，而门控思想后来更多以**门控卷积、注意力、LSTM/GRU** 等形式延续。

### 2.b DenseNet 与 ResNet 连接方式的本质不同及优缺点

**背景**：DenseNet（Huang et al., 2017, CVPR）在 ResNet 之后提出，同样基于"跨层连接"，但连接的"拓扑"不同。

**ResNet 的连接方式：逐元素相加（summation）**

```
xₗ₊₁ = xₗ + F(xₗ)
```

第 l+1 层只能"看到"前一层的输出 xₗ（残差块内也仅看块输入）。**连接是"链式"的：每层与紧邻的残差块相连。**

**DenseNet 的连接方式：通道拼接（concatenation）**

```
xₗ = Hₗ( [x₀, x₁, …, xₗ₋₁] )
```

第 l 层的输入是**之前所有层输出在通道维度上的拼接**，其输出又作为之后所有层的输入。**连接是"全互联"的：第 l 层与前面所有 l 层都直接相连**（故名 Densely Connected）。也因此 DenseNet 用窄层（每层只输出 k 个通道，k 为 growth rate）就能工作。

**本质不同**：ResNet 通过**加法**把信息"叠加"进同一特征空间（特征逐层被修正/精化）；DenseNet 通过**拼接**把信息"并联"保留在各层自己的通道里（每一层都能直接访问所有历史特征，特征复用而非覆盖）。

**优点**：

1. **特征复用极强**：浅层提取的低级特征（边缘、纹理）可被深层直接访问，无需担心在加法累积中被"冲淡"；
2. **梯度通路极多**：第 l 层到损失之间有 O(l) 条直接通路，梯度消失进一步缓解，训练更稳定，可用更少的参数达到同等精度；
3. **参数效率高**：由于特征复用，DenseNet 在 ImageNet 等任务上以显著更少的参数量/FLOPs 达到与 ResNet 相当甚至更好的性能，并带有一定的正则化效果（缓解过拟合，小数据集上优势明显）；
4. **隐式深度监督**：每一层都能直接接收来自损失的信号，类似辅助分类器的效果。

**缺点**：

1. **显存与计算开销大**：拼接导致后续层的输入通道数随深度线性增长（第 l 层输入通道 ≈ k·l），中后期的卷积计算量和激活值显存占用都很高，**实际训练吞吐往往不如同精度的 ResNet**；
2. **推理速度不占优**：密集连接对并行计算和硬件不友好（不规则的访问模式），部署成本高；
3. **深层时输入过宽**：极深的 DenseNet 会因拼接导致特征图过宽，需要 1×1 卷积（bottleneck 与 transition 层）压缩，设计复杂度上升；
4. **迁移到检测/分割等下游任务不如 ResNet 普遍**：因其特征图尺寸与通道的组织方式，作为骨干网络（backbone）的通用性弱于 ResNet/ResNeXt 等。

**一句话总结**：ResNet 是"**纵向叠加、链式连接**"——让信息无损穿越；DenseNet 是"**横向拼接、全互联连接**"——让信息充分复用。前者以极简换深度，后者以连接密度换参数效率，代价是显存与速度。
